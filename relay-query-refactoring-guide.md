# Relay Query Refactoring Guide: Multiple Queries to Single Query + Fragments

Deep dive into converting `useLazyLoadQuery` and `usePreloadedQuery` patterns to use fragments for optimized data fetching.

---

## Problem Statement

**Current State:**
- Parent component (`SingleSkill`) uses `useLazyLoadQuery` for skill info
- `TeacherSingleSkill` uses `useQueryLoader` for presigned URLs
- Student view may have separate queries
- **Result:** Multiple network requests (2+ round trips)

**Target State:**
- Single `useLazyLoadQuery` in parent
- Child components use fragments
- **Result:** One optimized network request

---

## Core Concepts

### 1. useLazyLoadQuery vs usePreloadedQuery

#### useLazyLoadQuery
```typescript
const data = useLazyLoadQuery(
  graphql`query MyQuery($id: ID!) { user(id: $id) { name } }`,
  {id: '4'}
);
```

**Purpose:** Fetch query when component renders

**Issues:**
- Waits until render to start data fetch
- Can trigger waterfall requests if nested
- Not ideal for performance-critical paths

#### usePreloadedQuery
```typescript
const data = usePreloadedQuery(
  graphql`query MyQuery($id: ID!) { user(id: $id) { name } }`,
  queryReference  // Preloaded via loadQuery()
);
```

**Purpose:** Access data fetched by `loadQuery()` or `useQueryLoader()`

**Benefits:**
- Implements "render-as-you-fetch" pattern
- Can fetch before component renders
- Better performance (fetches earlier)

---

### 2. Fragment Keys ($ref)

Fragment keys are objects returned from Relay that tell `useFragment` where to read data from.

```typescript
// Fragment definition
const UserFragment = graphql`
  fragment UserFragment on User {
    name
    email
  }
`;

// Fragment reference (comes from query where fragment was spread)
type Props = {
  user: UserFragment$key;  // Generated type
};

function UserComponent({ user }: Props) {
  const data = useFragment(UserFragment, user);
  return <div>{data.name} - {data.email}</div>;
}
```

**Key Points:**
- `UserFragment$key` is generated by Relay compiler
- Represents "where to read from" (not the actual data)
- Enables data masking (only `useFragment` can access the data)
- Pass fragment reference (`$ref`), not raw data

---

### 3. Data Masking

Relay hides data unless a component explicitly asks for it via `useFragment`.

```typescript
// Parent query
const ParentQuery = graphql`
  query ParentQuery {
    user {
      ...UserFragment  // Fragment spread creates fragment key
    }
  }
`;

// Child component
function ParentComponent() {
  const data = useLazyLoadQuery(ParentQuery, {});
  // data.user is a FRAGMENT KEY, not user data
  // You cannot access: data.user.name  <-- This will error!

  return <UserComponent user={data.user} />;  // Pass fragment key
}

// UserComponent can access name/email via useFragment
function UserComponent({ user }: { user: UserFragment$key }) {
  const userData = useFragment(UserFragment, user);  // Unmasks data
  return <div>{userData.name}</div>;  // Now accessible
}
```

**Why Data Masking?**
- Prevents accidental coupling to parent data
- Makes components self-contained
- Allows safe removal of fields
- Ensures components declare ALL dependencies

## Refactoring Strategy

### Step 1: Create Fragment for Child Component

**Before:**
```typescript
// TeacherSingleSkill.tsx
export default function TeacherSingleSkill({ skillId }: { skillId: string }) {
  const data = useLazyLoadQuery(
    graphql`
      query TeacherSingleSkillQuery($skillId: ID!) {
        skill(id: $skillId) {
          title
          description
          presignedUrls {
            url
          }
        }
      }
    `,
    { skillId }
  );

  return <SkillDisplay skill={data.skill} />;
}
```

**After:**
```typescript
// TeacherSingleSkill.tsx
import { graphql, useFragment } from 'react-relay';
import type { TeacherSingleSkillFragment$key } from './__generated__/TeacherSingleSkillFragment.graphql';

// Define fragment
const TeacherSingleSkillFragment = graphql`
  fragment TeacherSingleSkillFragment on Skill {
    title
    description
    presignedUrls {
      url
    }
  }
`;

// Update props to accept fragment key
type Props = {
  skill: TeacherSingleSkillFragment$key;
};

export default function TeacherSingleSkill({ skill }: Props) {
  const data = useFragment(TeacherSingleSkillFragment, skill);
  return <SkillDisplay skill={data} />;
}
```

**Changes:**
1. Extract query fields into fragment
2. Use `useFragment` to read data
3. Update Props type to `TeacherSingleSkillFragment$key`
4. Run `npm run relay` to regenerate types

---

### Step 2: Update Parent Query to Spread Fragment

**Before:**
```typescript
// SingleSkill.tsx
export default function SingleSkill({ skillId }: { skillId: string }) {
  // Parent fetches skill info
  const skillData = useLazyLoadQuery(
    graphql`
      query ParentSkillQuery($skillId: ID!) {
        skill(id: $skillId) {
          title
          description
          // ... other skill fields
        }
      }
    `,
    { skillId }
  );

  // TeacherSingleSkill fetches presigned URLs separately
  // This is where the second network request happens
  return (
    <TeacherSingleSkill
      skillId={skillId}  // Triggers second query
    />
  );
}
```

**After:**
```typescript
// SingleSkill.tsx
import { graphql, useLazyLoadQuery } from 'react-relay';
import type { TeacherSingleSkillFragment$key } from './TeacherSingleSkill/__generated__/TeacherSingleSkillFragment.graphql';

// Import fragment reference (or define here if not exported)
import { TeacherSingleSkillFragment } from './TeacherSingleSkill';

// Combined query
const SingleSkillQuery = graphql`
  query SingleSkillQuery($skillId: ID!) {
    skill(id: $skillId) {
      title
      description
      // Spread child fragment
      ...TeacherSingleSkillFragment
      // ... other parent fields
    }
  }
`;

export default function SingleSkill({ skillId }: { skillId: string }) {
  // Single fetch gets everything!
  const data = useLazyLoadQuery(
    SingleSkillQuery,
    { skillId }
  );

  // Pass fragment key ($ref), not skill data
  return (
    <TeacherSingleSkill
      skill={data.skill}  // This is a fragment key now
    />
  );
}
```

**Changes:**
1. Create combined query
2. Spread `TeacherSingleSkillFragment` into skill selection
3. Pass `data.skill` (fragment key) to child
4. Remove `useQueryLoader` + `useEffect` for secondary loads

### Step 3: Handle Student View (Optional)

**If StudentSingleSkill has queries:**

```typescript
// StudentSingleSkill.tsx
import { graphql, useFragment } from 'react-relay';
import type { StudentSingleSkillFragment$key } from './__generated__/StudentSingleSkillFragment.graphql';

// Define student-specific fragment
const StudentSingleSkillFragment = graphql`
  fragment StudentSingleSkillFragment on Skill {
    title
    description
    studentProgress {
      completed
      score
    }
    // Spread teacher fragment if needed
    ...TeacherSingleSkillFragment
  }
`;

type Props = {
  skill: StudentSingleSkillFragment$key;
};

export default function StudentSingleSkill({ skill }: Props) {
  const data = useFragment(StudentSingleSkillFragment, skill);
  return <StudentView skill={data} />;
}
```

**Spread into parent query with @skip directive:**

```typescript
const SingleSkillQuery = graphql`
  query SingleSkillQuery(
    $skillId: ID!
    $isStudent: Boolean! = false
  ) {
    skill(id: $skillId) {
      title
      description
      ...TeacherSingleSkillFragment
      ...StudentSingleSkillFragment @include(if: $isStudent)
    }
  }
`;

// Usage
export default function SingleSkill({ skillId, isStudent }: Props) {
  const data = useLazyLoadQuery(
    SingleSkillQuery,
    { skillId, isStudent }
  );

  // Conditional component rendering
  if (isStudent) {
    return <StudentSingleSkill skill={data.skill} />;
  }
  return <TeacherSingleSkill skill={data.skill} />;
}
```

## Advanced Patterns

### Fragment Arguments

Pass arguments to fragments for dynamic behavior:

```typescript
const ImageFragment = graphql`
  fragment ImageFragment on Image
  @argumentDefinitions(
    width: { type: "Int", defaultValue: null }
    height: { type: "Int", defaultValue: null }
  )
  {
    url(
      width: $width,
      height: $height
    )
    altText
  }
`;

// Spread with arguments
const SkillQuery = graphql`
  query SkillQuery {
    skill {
      thumbnail {
        ...ImageFragment @arguments(width: 400, height: 300)
      }
      poster {
        profilePic {
          ...ImageFragment @arguments(width: 100, height: 100)
        }
      }
    }
  }
`;

// Use in component
function SkillComponent() {
  const data = useLazyLoadQuery(SkillQuery, {});
  return <Image image={data.skill.thumbnail} />;
}

function ImageComponent({ image }: { image: ImageFragment$key }) {
  const data = useFragment(ImageFragment, image);
  return <img src={data.url} alt={data.altText} />;
}
```

**Benefits:**
- Fetch optimized image sizes per context
- Reduce bandwidth
- Better UX (faster loads)

### useQueryLoader Pattern

For "render-as-you-fetch" with navigation:

```typescript
import { useQueryLoader, usePreloadedQuery } from 'react-relay';

const SingleSkillQuery = graphql`
  query SingleSkillQuery($skillId: ID!) {
    skill(id: $skillId) {
      ...TeacherSingleSkillFragment
    }
  }
`;

type Props = {
  skillId: string;
  initialQueryRef: PreloadedQuery<SingleSkillQueryType>;
};

export default function SingleSkill({ skillId, initialQueryRef }: Props) {
  // Load query reference into state
  const [queryReference, loadQuery, disposeQuery] = useQueryLoader(
    SingleSkillQuery,
    initialQueryRef
  );

  // Access data via usePreloadedQuery
  const data = usePreloadedQuery(SingleSkillQuery, queryReference);

  return (
    <Suspense fallback={<Loading />}>
      {queryReference && <TeacherSingleSkill skill={data.skill} />}
    </Suspense>
  );
}

// Router preloads:
const queryRef = loadQuery(environment, SingleSkillQuery, { skillId });
// Pass to component: <SingleSkill initialQueryRef={queryRef} />
```

**Benefits:**
- Fetch before navigation
- Smooth transitions
- Avoid layout shift

**Important:**
- `useQueryLoader` automatically disposes old queries
- Better than `loadQuery()` directly (manual disposal)

## Common Pitfalls

### 1. Forgetting to Spread Fragment
```typescript
// ❌ Wrong: Fragment not spread into query
const ParentQuery = graphql`
  query ParentQuery {
    skill {
      title
      // ...TeacherSingleSkillFragment  <-- Missing!
    }
  }
`;

// ✅ Right: Spread fragment
const ParentQuery = graphql`
  query ParentQuery {
    skill {
      title
      ...TeacherSingleSkillFragment
    }
  }
`;
```

### 2. Passing Wrong Type
```typescript
// ❌ Wrong: Passing raw data instead of fragment key
function ParentComponent() {
  const data = useLazyLoadQuery(ParentQuery, {});
  return <TeacherSingleSkill skill={data.skill.title} />;  // Wrong!
}

// ✅ Right: Pass fragment key
function ParentComponent() {
  const data = useLazyLoadQuery(ParentQuery, {});
  return <TeacherSingleSkill skill={data.skill} />;  // Correct
}
```

### 3. Not Running Relay Compiler
After adding fragments:
```bash
npm run relay  # Regenerates __generated__ folder
```

Without running compiler, TypeScript will error on generated types.

### 4. Missing Fragment in Parent Query
```typescript
// ❌ Wrong: Fragment defined but not used
const TeacherSingleSkillFragment = graphql`...`;
// Not spread in any query!

// ✅ Right: Spread into query
const ParentQuery = graphql`
  query ParentQuery {
    skill {
      ...TeacherSingleSkillFragment  <-- Must be here!
    }
  }
`;
```

## Quick Reference

### Hook Comparison

| Hook | Purpose | When to Use |
|-------|-----------|--------------|
| `useLazyLoadQuery` | Fetch on render | Simple pages, no prefetch |
| `loadQuery` | Preload data | Navigation, prefetching |
| `useQueryLoader` | Manage preloaded refs | Route transitions |
| `usePreloadedQuery` | Read preloaded data | Read from `loadQuery` |
| `useFragment` | Read fragment data | All component data needs |

### Fragment Pattern

```typescript
// 1. Define fragment
const MyFragment = graphql`
  fragment MyFragment on Type {
    field1
    field2
  }
`;

// 2. Use in component
type Props = {
  data: MyFragment$key;  // Generated type
};

function MyComponent({ data }: Props) {
  const actualData = useFragment(MyFragment, data);
  return <div>{actualData.field1}</div>;
}

// 3. Spread in parent query
const ParentQuery = graphql`
  query ParentQuery {
    item {
      ...MyFragment  // Spread here
    }
  }
`;
```
