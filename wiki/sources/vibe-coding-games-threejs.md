# Vibe Coding Games with ThreeJS

**Source:** 2026-01-30 - Vibe Coding Games with ThreeJS.md
**Date ingested:** 2026-04-21
**Type:** Twitter thread analysis

## Summary

@chongdashu demonstrates that building games through vibe coding is now viable using ThreeJS + multiple AI agents. The key insight is progressive skill improvement: each game built updates the skill file, creating a compounding learning loop.

## Key Claims

- ThreeJS knowledge is the bottleneck, not AI capabilities
- Progressive skill improvement through bug/issue updates compounds across projects
- Multi-agent workflow (Claude Code + Codex + Nano Bana Pro) beats single agent
- Author built 4 playable games in one week (endless runner, tower defense, mini-game, arena shooter)

## The Workflow

1. Learn ThreeJS basics (prerequisite)
2. Design game concept (Nano Bana Pro for game design + technical specs)
3. Code with AI agents (Claude Code / Codex for implementation)
4. Play and debug (identify bugs, issues, improvements)
5. Update skill (refine prompting based on what went wrong)
6. Repeat (next game builds on improved skill)

## Progressive Improvement Loop

```
Build → Play → Find bugs → Update skill → Build better next time
```

This is the same pattern as [[self-improvement-loop]] applied to creative work. The "update skill based on bugs" is manual MISS/FIX logging.
