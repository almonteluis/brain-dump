## Summary

Comprehensive documentation of vault automation scripts and the progressive disclosure framework for navigating the Obsidian vault. Covers vault-tree-generator.sh, vault-ops.sh, spatial editing, hooks integration, and workflows including Universal Mining Framework, Daily Note Templates, and Article Processing Pipeline.

## Key Claims

- Progressive disclosure uses 4 layers: File Tree (Layer 1), YAML Descriptions (Layer 2), Outline (Layer 3), Full Content (Layer 4)
- Spatial editing allows inline edit instructions in curly braces `{like this}` to be processed later
- Universal Mining Framework extracts both explicit (Layer 1) and implicit (Layer 2) content from all inputs
- All inputs reveal new reality — the vault must be updated to match
