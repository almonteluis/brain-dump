# When AI writes almost all code, what happens to software engineering?

**Source:** When AI writes almost all code, what happens to software engineering?.md
**Date ingested:** 2026-04-29
**Type:** Industry analysis

## Summary

Gergely Orosz explores the shift from AI as assistant to AI as primary code author, citing real experiences from prominent engineers who now commit 90-100% AI-generated code. The article examines what becomes more and less valuable in this new landscape.

## Key Claims

- **Karpathy's flip:** From "it's slop" (Oct 2025) to "profession being dramatically refactored" (Dec 2025). New skill: mastering the "programmable layer of abstraction" above code (agents, prompts, contexts, memory, modes, MCP, LSP, skills, hooks)
- **Boris Cherny:** 200 PRs in one month, every line AI-written. Didn't open IDE at all
- **DHH flipped stance:** Resistance was partly because models weren't good enough. Now they are
- **Malte Ubl (Vercel CTO):** "Cost of software production is trending towards zero"
- **Peter Steinberger:** Stopped reading generated code. Watches the stream, knows structure and design decisions

### Declining Value

- **Prototyping** — non-technical folks can now build via Lovable, Replit
- **Language polyglot** — AI handles syntax across languages
- **Frontend/backend specialization** — startups will hire generalists who use AI across the stack
- **Well-defined ticket implementation** — Cursor auto-implements Linear tickets
- **Refactoring by hand** — spell out the refactor, AI executes faster

### Rising Value

- **Tech lead traits** — architecture decisions, system design, reviewing AI output
- **Product-minded engineers** — understanding user problems, not just implementing specs
- **Specification writers** — precise requirements become the bottleneck, not implementation
- **Validation and testing** — ensuring AI-generated code is correct
