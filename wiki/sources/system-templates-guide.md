# Daily Note Templates Guide

**Source:** raw/06_system/templates/README.md
**Date ingested:** 2026-04-09
**Type:** documentation

## Summary

Guide for using daily note templates — which template to use when and why. Two templates available: Full (comprehensive tracking) and Quick (minimal, fast check-ins). Includes quick start options, when to use each template, and best practices for consistent daily note-taking.

## Key Claims

- Full template: Comprehensive tracking with work, learning, personal, insights, health, reflections
- Quick template: Minimal tracking with done, learned, key insight, tomorrow priorities
- Consistency > completeness — fill template every day even if brief
- Use wiki-links to connect daily notes to related vault notes
