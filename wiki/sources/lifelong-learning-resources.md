## Summary

Curated list of 88+ resources (newsletters, books, videos, websites) for software engineers. Organized by category: web dev, system design, leadership, general growth. Author emphasizes applying knowledge immediately rather than consuming passively.

## Key Claims

1. **Don't read everything at once** — Pick 2-3 newsletters matching current priorities. Come to rest when needed.
2. **Apply immediately** — If you can't apply knowledge from a book in day-to-day work, postpone reading it.
3. **The 10-20% rule** — True wisdom is finding the small fraction of a book to apply at the moment. Don't try 100%.
4. **No courses listed** — Author's preferred learning method is reading + immediate application in job/side-projects.
5. **Second Brain for retention** — Uses minimalistic productivity system based on Building a Second Brain.
