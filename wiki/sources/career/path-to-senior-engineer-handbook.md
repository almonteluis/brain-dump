## Summary

GitHub repo curating ~250+ resources to help engineers reach Senior Software Engineer and beyond. Covers newsletters, books, courses, papers, YouTube channels, podcasts, communities, and LinkedIn profiles to follow. Functions as a one-stop bookmark hub for career growth, technical depth, leadership, and soft skills.

Closely adjacent to existing [[lifelong-learning-resources]] (88+ generic continuous-learning resources) but with a specific career-progression lens (Mid-level → Senior → Staff).

## Key Themes

1. **Soft skills + technical depth, equally weighted** — communication, persuasion, and leadership books outweigh pure-tech in the list. Aligns with [[ai-as-management-skill]] thesis: senior-level work shifts from execution to coordination.
2. **Newsletter-first learning** — heavy newsletter weighting reflects how senior-eng learning happens in practice (asynchronous, signal-rich, time-bounded).
3. **System design as a career milestone** — separate book + course + newsletter sections; reinforces system design as an explicit Senior promotion-readiness skill.
4. **Distributed-systems classics still load-bearing** — six 2003–2012 papers are the canonical set; durable knowledge worth re-reading vs constant new content.
