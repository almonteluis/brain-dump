# JavaScript Types

**Source:** raw/02_reference/software-engineer/Languages/JavaScript/JavaScript Types.md
**Date ingested:** 2026-04-09
**Type:** technical reference

## Summary

JavaScript is a dynamically typed language with two main categories: primitive types and reference types. Understanding type behavior is fundamental to writing reliable code.

## Key Claims

- JavaScript has primitive and reference type categories
- Type coercion happens implicitly and explicitly
- Understanding types prevents common bugs

## Type Categories

### Primitive Types
- String
- Number
- Boolean
- Null
- Undefined
- Symbol
- BigInt

### Reference Types
- Object
- Array
- Function
- Date
- RegExp

## Type Coercion

- **Implicit** — Automatic type conversion
- **Explicit** — Manual type casting
- Understanding coercion prevents unexpected behavior
