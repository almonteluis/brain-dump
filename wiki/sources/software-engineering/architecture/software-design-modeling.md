# Software Design and Modeling

**Source:** raw/02_reference/software-engineer/Architecture/Design/Software Design and Modeling.md
**Date ingested:** 2026-04-09
**Type:** technical reference

## Summary

Software design is a process to document structural components and behavioral attributes using diagrams, flowcharts, and Unified Modeling Language (UML).

## Key Claims

- Structured design uses hierarchical modules that are cohesive and loosely coupled
- UML diagrams are programming language agnostic and divided into structural and behavioral categories
- State transition diagrams show object state changes based on events
- Interaction diagrams show object interactions and their order

## Diagram Types

| Type | Purpose |
|------|---------|
| Structure Diagrams | Static structure at different abstraction levels |
| UML Diagrams | Visual architecture communication |
| State Transition | Object state changes based on events |
| Interaction Diagrams | Object interactions and sequencing |

## Best Practices

1. Start with high-level design
2. Focus on clarity
3. Maintain consistency
4. Design for change
5. Document assumptions
6. Review and refine
7. Ensure traceability
