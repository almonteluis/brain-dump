# Testing Types Overview

**Source:** raw/02_reference/software-engineer/frontend/Patterns/Testing your apps.md
**Date ingested:** 2026-04-09
**Type:** technical reference

## Summary

Testing applications involves checking code to ensure it meets requirements, functions correctly, and maintains quality. Automated testing is preferred over manual testing, especially for code that changes frequently.

## Key Claims

- Automated testing is key to continuous integration and continuous delivery
- Manual testing is done by humans clicking through the app
- Automated tests run via machines executing test scripts

## Testing Types

| Type | Purpose |
|------|---------|
| Unit Test | Test individual methods and functions |
| Integration Test | Verify modules/services work together |
| Functional Test | Focus on business requirements |
| End-to-End | Recreate user behavior in complete environment |
| Performance Test | Check app performance under workload |
| Smoke Test | Basic functionality checks |
