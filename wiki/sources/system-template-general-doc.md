# General Documentation Template

**Source:** raw/06_system/templates/general-documentation-template.md
**Date ingested:** 2026-04-09
**Type:** template

## Summary

General template for Confluence-style technical documentation. Includes YAML frontmatter, title, one-sentence description, table of contents, sections with subsections, code examples, and See also links. Designed for flexible use across documentation types.

## Key Claims

- Structure: YAML → Title → Description → TOC → Sections → See also
- Code examples specify language (typescript, bash, sql)
- Table of contents links to section anchors
- See also section for internal and external links
