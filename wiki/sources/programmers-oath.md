# The Programmer's Oath

**Source:** Widdershinprogrammers-oath An oath for programmers, comparable to the Hippocratic Oath.md
**Date ingested:** 2026-04-22
**Type:** reference

## Summary

A 12-tenet professional oath for software developers, modeled after the Hippocratic Oath in medicine and the Obligation of the Engineer. Created by Nick Johnstone (Widdershin) as a living document on GitHub, it addresses ethical obligations, professional humility, user privacy, code responsibility, and interpersonal kindness. The project is endorsed by the Center for Humane Technology and supports a versioned signing mechanism where signatories commit to a specific commit hash.

## Key Claims

- Programmers have ethical obligations comparable to those in medicine and engineering
- Code is written for people, not computers — human factors outweigh technical cleverness
- Privacy is a fundamental responsibility: user data should only be used for its intended purpose
- Admitting ignorance ("I don't know") is a professional strength, not a weakness
- Programmers must consider consequences of their code, especially in matters of life or death
- The oath is a living document that evolves through community contribution

## The 12 Tenets

1. **Honest work** — Only undertake honest and moral work; resist requirements that harm people unnecessarily
2. **Knowledge sharing** — Respect lessons from predecessors and share learnings with successors
3. **Art and science** — Programming is both; warmth, empathy, and understanding may outweigh clever algorithms
4. **Ask for help** — Never be ashamed to say "I don't know"; ask for help when stuck
5. **User privacy** — Respect user privacy; use their data only for its entrusted purpose
6. **Humility** — Recognize that mistakes will be made
7. **Life and death** — Tread most carefully when code affects human safety
8. **Write for people** — Code is written for people, not computers
9. **Consider consequences** — Respect the difficulties of both social and technical problems
10. **Diligence** — Be diligent and take pride in work
11. **Open mind** — Recognize you can be wrong; listen to others carefully and with respect
12. **Kindness** — Be kind to fellow programmers; never feign surprise or disparage others' code

## Signing Mechanism

- Public signatures recorded in a SIGNATURES file with commit hash
- Commit hash serves as the "version" of the oath signed
- Signatories can upgrade or downgrade to different versions via pull request
- Signers are encouraged to follow the repository for updates and re-sign as needed
