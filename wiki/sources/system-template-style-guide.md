**Source:** raw/06_system/templates/technical-documentation-style-guide.md

## Summary

Writing style guide for team technical documentation. Covers file structure with YAML frontmatter, core structure (title, TOC, sections, See also), section types for services/components/conventions/processes, writing guidelines (tone, formatting, code examples), and anti-patterns to avoid.

## Key Claims

- Required YAML: title, description, tags (work, confluence, documentation + topical)
- Service docs: Purpose, Technology, Connections, Details, See also
- Convention docs: Overview, Categories, Examples, Resources
- Tone: Professional but approachable, direct and concise, explain "why"
