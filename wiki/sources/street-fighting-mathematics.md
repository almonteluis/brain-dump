# MIT Street-Fighting Mathematics

**Source:** 2026-01-30 - MIT Street Fighting Mathematics.md
**Date ingested:** 2026-04-21
**Type:** Book/course summary

## Summary

MIT course by Sanjoy Mahajan teaching educated guessing and opportunistic problem solving. The core insight: traditional mathematical rigor prevents real problem solving. Life hands us partly defined problems needing only moderately accurate solutions.

## Key Claims

- "Rules are for fools: do whatever works — don't just stand there"
- Perfectionism prevents action; educated guessing beats exact calculation for most real decisions
- Six reusable tools apply across domains (physics, CS, biology, management)
- Separate tool from application to enable reuse

## The Six Tools

| Tool | What It Does | SE Application |
|------|-------------|----------------|
| Dimensional Analysis | Check units and consistency | Validating formulas, checking dependencies |
| Easy Cases | Test simple scenarios first | Edge case testing, unit tests |
| Lumping | Group similar quantities | Capacity planning, system sizing |
| Picture Proofs | Visual reasoning | Architecture diagrams, data flow |
| Successive Approximation | Start rough, refine iteratively | MVP approach, iterative development |
| Reasoning by Analogy | Use similar problems as guides | Pattern recognition, cross-domain learning |

## Key Insight

Traditional math teaches solving exactly stated problems exactly. Real life presents partly defined problems needing moderately accurate solutions. The gap: we fear unjustified leaps even when they land on correct results.
