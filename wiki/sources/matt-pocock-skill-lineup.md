# Matt Pocock Skill Lineup

**Source:** `raw/Thread by @mattpocockuk.md`
**Date ingested:** 2026-04-17
**Type:** Twitter thread

## Summary

Matt Pocock's custom Claude Code skill lineup replacing earlier tools with a streamlined set focused on domain modeling, PRDs, issues, triage, and TDD.

## The Skill Lineup

| Skill | Purpose |
|-------|---------|
| `/domain-model` | Replaces `/grill-me`, integrates DDD concepts, adds docs & ADRs during discussions |
| `/to-prd` | Create a Product Requirements Document |
| `/to-issues` | Create issues with blocking relationships |
| `/github-triage` | Triage issues with state machine-based labeling |
| `/tdd` | TDD where appropriate |

## Key Insight

> "You've got to own the process. If you outsource it to GSD/BMAD/Spec-Kit you end up with a huge ball of mud."

Custom workflows beat off-the-shelf frameworks because they encode your specific domain knowledge and preferences.
