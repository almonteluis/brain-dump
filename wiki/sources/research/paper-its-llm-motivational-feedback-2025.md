## One-line signal
Proposes an ITS-LLM architecture that integrates large language models into the Tutoring Model of [[Intelligent Tutoring Systems]] to generate motivational feedback, validated with a Llama 3.2 prototype.

## Core ideas
- Defines a formal ITS-LLM architecture for embedding LLMs within the tutoring model of traditional ITS
- LLMs can effectively generate motivational feedback tailored to student states
- Validated via prototype implementation using Llama 3.2 model
- Motivational feedback generation is a distinct capability from instructional/cognitive feedback
- Architecture is designed to be modular — LLM component can be swapped or upgraded independently
- Builds on prior work showing LLMs improve student engagement in learning environments

## Why this matters for the Three-Ring project
Directly relevant: demonstrates how to architect LLM integration specifically for motivational feedback in educational software. The ITS-LLM architecture pattern could inform how Three-Ring generates motivationally-appropriate messages for students based on their learning state.
