# LLM Motivational Feedback in ITS (2025)

Paper exploring whether LLMs can generate motivational feedback in intelligent tutoring systems. The appeal is obvious: a teacher can say "you're really getting the hang of this" and mean it. An LLM can generate syntactically identical text, but the kid knows it's a machine. Does that matter?

This is relevant to [[project-atlas]] because the feedback layer is where LLMs could add the most value — not checking answers (that's deterministic) but doing the motivational, metacognitive, relational work that current systems can't. The risk is [[critical-ai-literacy|the kid recognizing the AI's output as hollow]], which could backfire worse than no feedback at all.
