# Cognitive Learning Model

Source: [Confluence — Cognitive Learning Model](https://newclassrooms.atlassian.net/wiki/spaces/PRODUCT/pages/607879169/Cognitive+Learning+Model)

## Introduction

The implicit model of learning in school: student pays attention to input, then either learns it or doesn't. Once learned, they move on. Cognitive science provides a more complex model.

## The 3-Phase Model

| Phase | Description | Product Tie-In |
|-------|-------------|----------------|
| **Attention** | Enables learning to occur. Curricula, lessons, worksheets, games all attempt to direct attention. | Getting the right input to the right students (skill recommendations, groupings) |
| **Comprehension** | Heavy cognitive lifting — encoding information into existing mental structures. | New lesson content targeting insight and intuition |
| **Consolidation** | Internalization through repeated retrieval and encoding. | Spaced practice systems |

## Application to Product Exploration

Every feature should have a clear tie back to this model (direct or indirect):

- **New lesson content** → facilitates comprehension (generating insight and intuition)
- **Spaced practice system** → optimizes consolidation
- **Skill recommendations / student groupings** → attention (right input to right students)
