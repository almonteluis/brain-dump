# Sources

Raw source materials processed into the wiki. These are the original articles, notes, and documents before synthesis.

## Structure

```
sources/
├── articles/          # External articles and blog posts
├── ai-ml/             # AI/ML related content
├── architecture/      # System design and architecture docs
├── archive/           # Outdated or personal notes (marvin files, etc)
├── education/         # Education and learning content
│   └── btech/         # NC/BTech specific education content
├── frontend/          # Frontend development (React, patterns, etc)
├── obsidian/          # Obsidian-related content
├── patterns/          # Design and coding patterns
├── people/            # Career advice and people profiles
├── software-engineering/ # General software engineering
└── tools/             # Development tools and workflows
└── *.md               # Uncategorized sources (to be organized)
```

## Naming

All files use `kebab-case.md`. Files with spaces have been renamed.

## Processing

Sources are processed into `concepts/`, `entities/`, and `synthesis/` via `/second-brain-ingest`.
