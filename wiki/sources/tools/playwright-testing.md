# E2E Testing with Playwright

**Source:** raw/02_reference/software-engineer/frontend/Patterns/End-to-End testing with Playwright.md
**Date ingested:** 2026-04-09
**Type:** technical reference

## Summary

Playwright is an open-source automation framework developed by Microsoft for end-to-end testing of web applications.

## Key Claims

- Single API automates Chromium, Firefox, and WebKit
- Cross-platform: Windows, macOS, Linux
- Multi-language support: JavaScript, TypeScript, Python, .NET
- Modern alternative to Selenium

## Features

- **Browser Contexts**: Isolated browser sessions for parallel testing
- **Auto-wait**: Automatically waits for elements to be ready
- **Tracing**: Capture screenshots, videos, network logs on failure
- **Visual Testing**: Compare screenshots for UI regressions
- **Code Generation**: Record user actions to generate tests

## When to Use

- Critical user workflow validation
- Cross-browser testing
- Visual regression testing
- API + UI integration testing
