# E2E Testing

**Source:** raw/02_reference/software-engineer/frontend/Patterns/E2E Testing.md
**Date ingested:** 2026-04-09
**Type:** technical reference

## Summary

End-to-end testing verifies that application workflows function correctly from start to finish. Modern E2E tools provide powerful capabilities for automating user interactions and validating application behavior.

## Key Claims

- Tests complete user workflows
- Validates integration of all system components
- Catches issues unit tests miss
- Essential for critical user paths

## Tools

### Playwright
- Microsoft's automation framework
- Cross-browser (Chromium, Firefox, WebKit)
- Supports JavaScript, TypeScript, Python, .NET
- Visual testing capabilities

### Cypress
- Test writing with command chaining
- Network stubbing and mocking
- Real-time reloads

## Coverage Areas

- Critical user paths
- End-to-end workflows
- Performance metrics
- Cross-browser compatibility
