# Bun v1.3.12

**Source:** [[Bun v1.3.12]]
**Date ingested:** 2026-04-29
**Type:** release notes

## Summary

Bun v1.3.12 release — 120 issues fixed (219 thumbs-up reactions). Major features: built-in headless browser automation, terminal markdown rendering, in-process cron scheduler, async stack traces for native errors, 2.3x faster URLPattern, 2x faster Bun.Glob.scan, cgroup-aware parallelism.

## Key Claims

1. **Bun.WebView** — Native headless browser automation with WebKit (macOS default) and Chrome backends. OS-level input dispatch (`isTrusted: true`). Playwright-style actionability waiting. CDP access on Chrome backend.
2. **`bun ./file.md`** — Renders Markdown directly in terminal as ANSI output. `Bun.markdown.ansi()` API. Kitty Graphics Protocol for inline images.
3. **In-process `Bun.cron()`** — Callback-based cron scheduler (complements OS-level persistent crons). No overlap, UTC scheduling, `--hot` safe, `Disposable`.
4. **Upgraded JavaScriptCore** — 1,650+ upstream commits. Explicit Resource Management (`using`/`await using`), JIT improvements, WebAssembly SIMD.
5. **Unix domain socket** now matches Node.js semantics (EADDRINUSE, auto-cleanup).
6. **TCP_DEFER_ACCEPT** for Bun.serve() on Linux — nginx-style optimization collapsing two epoll wake-ups into one.
7. **URLPattern** 2.3x faster — direct regex engine calls, eliminating 24 GC allocations per call.
