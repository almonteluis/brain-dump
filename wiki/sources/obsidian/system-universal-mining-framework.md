# Universal Mining Framework

**Source:** raw/06_system/UNIVERSAL-MINING.md
**Date ingested:** 2026-04-09
**Type:** documentation

## Summary

Systematic framework for extracting maximum value from meetings, articles, and links. Core philosophy: All inputs reveal new reality. Two-layer mining approach extracts both explicit content (features, frameworks, decisions) and implicit content (embedded ideas, implied philosophies, decisions by omission).

## Key Claims

- Layer 1 (Explicit): Feature ideas, project sparks, frameworks, philosophies, explicit decisions, status updates, action items, blockers
- Layer 2 (Implicit): Ideas embedded in problems, philosophies as asides, decisions by NOT deciding, implied priorities
- State synchronization updates project hubs to reflect post-processing reality
- Quality red flags: summary too short, only 1-2 ideas extracted, no frameworks from conceptual content
