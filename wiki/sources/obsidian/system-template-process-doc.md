# Process Documentation Template

**Source:** raw/06_system/templates/process-documentation-template.md
**Date ingested:** 2026-04-09
**Type:** template

## Summary

Template for process documentation like workflows, best practices, and procedures. Structure includes Overview, sequential Sections/Steps, Examples with code blocks, and Related practices. Designed for Confluence-style team documentation.

## Key Claims

- Table of contents links to main sections
- Overview explains what the process is for and why it matters
- Sections can be sequential steps or conceptual groupings
- Examples use code blocks for commands and configurations
