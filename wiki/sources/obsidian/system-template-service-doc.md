# Service Documentation Template

**Source:** raw/06_system/templates/service-documentation-template.md
**Date ingested:** 2026-04-09
**Type:** template

## Summary

Template for documenting services, components, or systems with their purpose, technology, and connections. Sections include Purpose (one-sentence overview), Technology (stack, frameworks, deployment), Connections (integrations), Details (technical specifics), and See also (related docs).

## Key Claims

- Purpose section: One sentence on what it does and why it exists
- Technology section: Language, Framework, Infrastructure
- Connections format: Bold component name + relationship description
- Details section: Configuration, usage patterns, gotchas
