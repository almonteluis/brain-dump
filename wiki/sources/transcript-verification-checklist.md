# Transcript Processing Verification Checklist

**Source:** raw/02_reference/tools/transcript-verification-checklist.md
**Date ingested:** 2026-04-09
**Type:** checklist

## Summary

Verification checklist for processing meeting transcripts — ensures all insights, decisions, philosophies, and status updates are captured and synced to the vault.

## Key Claims

- Mining transcripts requires exhaustive extraction, not just summarizing
- Red flags indicate incomplete processing (short summaries, few ideas extracted)
- State sync ensures vault reflects post-meeting reality
- Quality checks verify YAML, headings, and wiki-links

## Red Flags to Check Before Marking Complete

### Volume Flags
- [ ] Summary is appropriately detailed for meeting length
- [ ] All major topics covered (not just first 10%)
- [ ] Ratio of summary to transcript is reasonable

### Extraction Flags
- [ ] All explicit decisions captured
- [ ] All implicit decisions identified
- [ ] All feature ideas extracted (including casual mentions)
- [ ] All frameworks/philosophies documented
- [ ] All status changes reflected

### State Sync Flags
- [ ] Project hubs updated if applicable
- [ ] Action items assigned and tracked
- [ ] Decisions logged to relevant project notes
- [ ] Vault reflects post-meeting reality
