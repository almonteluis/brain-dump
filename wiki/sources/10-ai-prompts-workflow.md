## Summary

10 prompt templates sourced from a private GitHub of engineers and founders. Two are directly relevant to software engineering: brutal code review and production debugging.

## Engineering-Relevant Prompts

### Brutal Code Review (Prompt #6)

```text
Do a git diff.
Pretend you're a senior dev who HATES this implementation.
Tear it apart — what would you criticize,
refactor, or reject in a PR review?
```

Described as the most-used prompt by engineers in the source community.

### Production Bug Debugging (Prompt #8)

```text
Walk me through a systematic debug process with 10 diagnostic steps.
Include an environment diff checklist,
a logging strategy, and how to set up monitoring
to catch this next time.
Error: [ERROR]
```

Replaces 2 hours of Googling with structured diagnostic approach.
