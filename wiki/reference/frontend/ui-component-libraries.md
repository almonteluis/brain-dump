## Selection Criteria

When choosing a UI library:

1. **Open source preference** — Check for active GitHub repo
2. **Tailwind compatibility** — Ensure it uses Tailwind classes (not styled-components)
3. **Accessibility** — Look for ARIA support, keyboard navigation
4. **Customization** — Verify theme/color override capabilities
5. **Bundle size** — Check for tree-shaking support
