# Leonardo de Moura

Creator of the Lean theorem prover and Z3 SMT solver. Senior Principal Researcher at Microsoft Research.

## Key Facts

- **Lean:** Programming language + theorem prover. 12+ years of development. De facto choice for AI-based mathematical reasoning (ACM SIGPLAN 2025 Software Award)
- **Z3:** Widely-used SMT solver
- **Lean FRO:** 20-person team maintaining the platform
- **Mathlib:** 200,000+ formalized theorems, 750+ contributors
- **Enterprise use:** AWS verified Cedar auth engine, Microsoft verifying SymCrypt in Rust
- ** zlib → Lean:** AI converted zlib C library to Lean with machine-checked correctness proofs
