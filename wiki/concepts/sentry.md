# Sentry

Application monitoring platform that helps developers identify, track, and resolve errors in production. Provides real-time error tracking, performance monitoring, and release health metrics.

## Key Characteristics

- Real-time error tracking with stack traces
- Performance monitoring (APM)
- Release health and regression detection
- Source maps for minified code
- Breadcrumbs for error context
- Environment and release tagging
