# GraphQL

Query language for APIs and runtime for executing those queries against your data. Developed by Meta (Facebook) in 2012, open-sourced in 2015.

## Key Characteristics

- Clients request exactly the data they need
- Single endpoint for all operations
- Strong type system defined by schema
- Introspection for API discovery
- Real-time subscriptions support

## Core Operations

| Operation | Purpose |
|-----------|---------|
| Query | Read data |
| Mutation | Write/modify data |
| Subscription | Real-time updates |
