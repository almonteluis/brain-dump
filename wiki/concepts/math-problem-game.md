# Math Problem Game

Game design concept for making math problems feel less arbitrary. Core idea: math problems become pattern-recognition puzzles where abstraction tools trigger "eureka moments."

## Core Premise

Math problems lose students when they feel arbitrary. Good math game should trigger the moment of pattern recognition — the "click" just before the answer.

## Mechanics

1. **Abstraction tools** (diagrams, visual frames) surface hidden patterns in worked examples
2. **Creativity = pattern recognition** — ability to see connections between seemingly unrelated elements
3. **Eureka moment** — when a new pattern solves part or all of the problem
4. **Reward the click, not just the answer** — game mechanics target the recognition moment

## Design Principle

> "A good math game should trigger when a student has a eureka moment. It's because an abstraction tool (a diagram) was framing a worked example and surfacing a pattern they couldn't see before."
