# AI Code Generation

The shift from AI as coding assistant to AI as primary code author.

## Current State (2026)

- Google/Microsoft: 25-30% of new code is AI-generated
- Boris Cherny (Claude Code): 200 PRs/month, 100% AI-written
- Malte Ubl (Vercel): "Cost of software production trending towards zero"
- Peter Steinberger: Stopped reading generated code, watches the stream

## What Becomes Less Valuable

- Prototyping (non-technical folks can now build)
- Language polyglot expertise
- Frontend/backend specialization
- Well-defined ticket implementation
- Manual refactoring

## What Becomes More Valuable

- Tech lead traits (architecture, system design)
- Product-minded engineering
- Specification writing
- Validation and testing
- Agent orchestration
