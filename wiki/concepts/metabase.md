# Metabase

Open-source business intelligence tool that lets anyone ask questions and learn from data. Supports SQL and visual query builders, dashboards, and embedding.

## Key Characteristics

- Visual query builder (no SQL required)
- SQL editor for advanced queries
- Dashboard creation and sharing
- Embedding options: full app, modular SDK, static
- User groups and permissions
- Row-level security via user attributes
- Alerting and scheduled reports

## Embedding Options

| Type | Plan | Description |
|------|------|-------------|
| Static | OSS/EE | iframe with signed JWT |
| Full App | Pro/EE | Complete Metabase in iframe |
| Modular SDK | Pro/EE | React components |
