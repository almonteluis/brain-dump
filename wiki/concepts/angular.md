# Angular

Google's platform for building mobile and desktop web applications. Uses TypeScript as its primary language and follows a component-based architecture with dependency injection.

## Key Characteristics

- Component-based architecture with decorators
- Built-in dependency injection system
- Two-way data binding
- RxJS for reactive programming
- Angular CLI for scaffolding and build tooling
