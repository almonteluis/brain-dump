# Vibe Coding

Term coined by Andrej Karpathy (Feb 2025) for constructing apps and websites via AI prompts without traditional programming expertise.

## Definition

> "I just see stuff, say stuff, run stuff, and copy paste stuff, and it mostly works." — Andrej Karpathy

## Characteristics

- Hobbyists build functional software by describing desired behavior
- No need to understand underlying code mechanics
- Iterative: prompt → review → adjust prompt
- Platforms: Lovable, Replit, Cursor, Claude Code

## Implications

- Lowers barrier to software creation dramatically
- Shifts engineering value from syntax knowledge to design and specification
- "Accept All" workflow — not reading diffs, trusting AI output
