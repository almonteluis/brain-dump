# Tier sync between classroom and lab

Tier 1 (classroom) and Tier 2 (math lab) teachers are flying blind without a shared view of where each student actually is. The fix isn't more meetings — it's giving both tiers the same graph.

At New Classrooms, tier one is in-class instruction with a dedicated math teacher. Tier two is a supplemental lab where students work on bridging gaps — but it often devolves into study hall because the rotating lab teacher doesn't know what each kid needs. The program should be the bridge: each student's skill graph or report shows *this is where you are, this is what you completed, this is what you're working toward*. Both the classroom teacher and the lab teacher see the same data. The lab stops being free-for-all homework time and becomes directed practice that actually connects to what happened in class that morning.

The alternative — predetermining lab work by the math teacher or the program — only works if the feedback loop is tight. If a kid bombs a concept in tier one at 10am, the lab at 1pm should know. If the system can't close that loop fast enough, the lab teacher needs agency to pull from the graph themselves.

This rhymes with [[differentiated-instruction]] but from the infrastructure side — Tomlinson's framework assumes one teacher doing the differentiating. What happens when two teachers share one student across two rooms?
