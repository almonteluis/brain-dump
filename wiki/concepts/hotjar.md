# Hotjar

Behavior analytics platform that provides session recordings, heatmaps, and user feedback tools. Helps understand how users interact with web applications.

## Key Characteristics

- Session recordings replay user interactions
- Heatmaps visualize click, tap, and scroll behavior
- Feedback polls and surveys
- Funnel analysis
- User recruitment for research
