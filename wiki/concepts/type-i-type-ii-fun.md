# Type I vs Type II Fun

Framework from Dr. Jonathan Jenkins (clinical/sports psychologist, works with Patriots and Red Sox) for categorizing enjoyable experiences by their temporal reward structure.

## Definitions

| | Type I Fun | Type II Fun |
|---|---|---|
| **During** | Enjoyable | Demanding, often uncomfortable |
| **After** | Satisfying | Deeply rewarding |
| **Examples** | Beach days, dinners with friends | Tough workout, meditation, hard hike |
| **Analogy** | Pleasure | Growth |

## Application

Meditation is classic Type II fun — sitting still feels like a chore, time moves slowly, but afterward there's calmness and clarity. Like holding a plank at the end of Pilates: "not particularly appealing going into it, but deeply rewarding once done."
