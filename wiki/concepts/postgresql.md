# PostgreSQL

Advanced open-source relational database management system. Known for extensibility, SQL compliance, and robust feature set including JSON support, full-text search, and custom types.

## Key Characteristics

- ACID-compliant transactions
- Extensible type system
- JSON/JSONB support for semi-structured data
- Full-text search capabilities
- Replication and high availability
- Rich indexing options (B-tree, GiST, GIN, etc.)
