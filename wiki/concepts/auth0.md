# Auth0

Identity platform providing authentication and authorization as a service. Supports single sign-on (SSO), multi-factor authentication, and social identity providers.

## Key Characteristics

- Single sign-on across applications
- Universal login page
- Social identity providers (Google, GitHub, etc.)
- JWT token issuance
- User management and role-based access control
