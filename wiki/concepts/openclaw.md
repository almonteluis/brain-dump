# OpenClaw

Self-hosted open-source AI coding agent (formerly Moltbot / Clawdbot). Runs in the terminal and supports multiple LLM providers via Model Studio integration.

## Key Characteristics

- Self-hosted (data stays local)
- Terminal-based UI and web dashboard
- Compatible with Qwen, Claude, and other models
- Configurable via JSON config file
- Supports reasoning/thinking modes
