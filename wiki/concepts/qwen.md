# Qwen

Alibaba's large language model family. Offers both open-weight models and API services. Known for strong coding performance, multimodal capabilities, and competitive benchmarks against larger models.

## Model Family

| Model | Parameters | Type | Key Feature |
|-------|-----------|------|-------------|
| Qwen3.6-27B | 27B | Dense | Flagship coding, easy deployment |
| Qwen3.6-35B-A3B | 35B total / 3B active | MoE | Efficient inference |
| Qwen3.6-Plus | API-only | — | Premium API tier |
| Qwen3.6-Max-Preview | API-only | — | Preview tier |

## Key Characteristics

- Supports thinking and non-thinking modes
- Native multimodal (vision + text)
- OpenAI-compatible and Anthropic-compatible APIs
- Compatible with Claude Code, OpenClaw, Qwen Code
- `preserve_thinking` feature for agentic tasks
