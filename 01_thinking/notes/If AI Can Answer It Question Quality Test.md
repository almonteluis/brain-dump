# If AI Can Answer It, Is It a Good Question?

## The Insight

> "As a teacher, if I'm asking questions that are easily answered by A.I., am I asking the best questions?"

— Jennifer Parnell, history teacher at Lawrenceville School

## The AI Quality Filter

AI tools act as a **quality filter** for assessment design:

| Question Type | AI Can Answer | Implication |
|---------------|---------------|-------------|
| Fact recall | Yes | Not worth asking |
| Standard essay | Yes | Needs redesign |
| Analysis with sources | Partial | Better |
| In-class discussion | No | Still valuable |
| Oral explanation | No | Still valuable |
| Personal synthesis | No | Still valuable |

## What This Means

If your assessment can be cracked by ChatGPT, one of two things is true:

1. **You're measuring something AI does better** — In which case, why not have students use AI?
2. **You're not measuring what you care about** — In which case, redesign the assessment

## Jennifer Parnell's Approach

Instead of fighting AI, she integrated it:

1. **AI generates essay** → Students analyze for errors and rewrite
2. **Students submit essays** → AI provides feedback on source quality
3. **Class focuses on** → Critical thinking, not rote response

This turns AI from threat into tool.

## The Deeper Principle

This isn't just about education. It's about **human value in an AI age**.

If AI can do it, the question becomes:
- Should humans still do it?
- If yes, how do we make it meaningfully human?
- If no, what should humans do instead?
