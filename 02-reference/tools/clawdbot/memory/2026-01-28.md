# 2026-01-28

## Vision Command Created

Created `~/clawd/bin/vision` - a shell wrapper for the Z.ai MCP Vision Server.

**Usage:**
```bash
vision <command> <image/video> [prompt]
```

**Commands:**
- `analyze` - General image analysis
- `ocr` - Extract text/code from screenshots
- `error` - Diagnose error screenshots
- `ui` - Convert UI to code/prompts
- `diagram` - Understand technical diagrams
- `data` - Analyze charts/graphs/dashboards
- `compare` - Compare two UIs
- `video` - Analyze video (≤8MB, MP4/MOV/M4V)

**Examples:**
```bash
vision analyze screenshot.png "What's shown here?"
vision ocr terminal.png "Extract the code"
vision error error.png "Fix this bug"
vision ui design.png "Generate React code"
vision diagram arch.png "Explain the flow"
vision data chart.png "Summarize insights"
vision compare before.png after.png
vision video demo.mp4 "What happens?"
```

**Setup:**
- Added `~/clawd/bin` to PATH in `~/.bashrc`
- Script is executable at `~/clawd/bin/vision`
- Reload shell or run `source ~/.bashrc` to use immediately

**Cost:** 1/7th price of Sonnet, 3x usage quota (via Z.ai MCP server)
