**Issue:** Levi incorrectly removed a `{question}` comment from react-refactoring-catalog.md instead of responding to it in context.

**Lesson Learned:**
- When user runs `/edit <filename>`, DO NOT delete `{comments}` in curly braces

- Position of comment IS the context — no need to explain what it refers to
