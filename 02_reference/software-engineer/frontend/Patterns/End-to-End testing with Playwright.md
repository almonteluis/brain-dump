# E2E Testing with Playwright

## Overview



description: Notes and reference material about  End to  End testing with  Playwright.
---

[Playwright](https://playwright.dev/) is an open-source automation framework developed by Microsoft for end-to-end testing of web apps. It provides a single API to automate Chromium, Firefox, and Webkit browsers across Windows, macOS, and Linux. Playwright supports Javascript, Typescript, Python, & .Net.
