description: ## manual vs automated tests.
---


Testing your apps involves checking your code to ensure it meets requirements, functions correctly, and maintain quality.

### manual vs automated tests
manual testing is done in person by clicking through the app or interact with the software or APIs with the correct tools.

automated tests are performed by machines that runs a test script. Test can vary in complexity from checking a single method in a class to making sure that performing a sequence of complex actions in the UI leads to consistent results.

Automated testing is a key component in continuous integration and continuous delivery.

in summary go with automated testing instead of manual testing. Especially for code that I write at least.

## different types of testing in software
### Unit test
unit test consist in testing individual methods and functions of the classes, components, or modules used by your software.

### Integration tests
integration test verify that different modules or services used by your software work well together.

### Functional test
functional test focus on the business requirement of an app.

### End to End testing
end to end testing recreate a user behavior with the software in a complete software environment.

### Performance testing
performance test checks how a app performs under a particular workload. these tests help measure the reliability, speed, scalability and responsiveness of your app.

### smoke testing
smoke test are basic test that check the basic functionality of an app.
