# Daily Note Templates

Use these templates for consistent daily note-taking. Choose based on how much detail you want to capture.

## 📁 Templates

### 1. Full Daily Note Template
**File:** `daily-note-template.md`

**Use when:** You want comprehensive tracking of your day.

**Sections:**
- 📋 Today (Work, Learning, Personal)
- 💡 Key Insights (from multiple sources)
- 🎯 Tomorrow (priorities)
- 📝 Notes
- 🏃 Health (Exercise, Sleep, Water, Food)
- 📚 Read / Watched
- 💭 Reflections (What went well, What could be better, Learnings)

**Best for:** Daily journals, comprehensive tracking, detailed reviews.

---

### 2. Quick Daily Note Template
**File:** `daily-note-quick.md`

**Use when:** You want minimal, fast daily tracking.

**Sections:**
- 📋 Today (Done, Learned)
- 💡 Key Insight (one main insight)
- 🎯 Tomorrow (priorities)
- 📚 Read / Watched

**Best for:** Quick check-ins, minimalists, busy days.

## 📋 When to Use Each

### Use Full Template When:
- You want comprehensive daily journal
- Reviewing your day for patterns
- Tracking health and habits consistently
- Learning multiple things worth noting
- Want deep reflections on what worked / didn't work

### Use Quick Template When:
- Very busy day (2 min max)
- Minimal notes preferred
- Only 1-2 key things happened
- Quick check-in style
- Doing detailed daily review elsewhere

## 💡 Best Practices

### DO ✅
- Fill template every day (consistency > completeness)
- Be specific in insights (not "good day" but "learned 5-Layer Prompt Architecture")
- Rate content with stars (⭐⭐⭐)
- Link to related vault notes via [[wiki-links]]
- Use today's reflections to improve tomorrow

### DON'T ❌
- Skip sections because "nothing to write" (write "N/A" instead)
- Be vague ("learned something" vs "learned 5-Layer Prompt Architecture")
- Only track work (learning + personal matter too)
- Leave template blank (it creates habit of not filling it)
